# 搜刮音效教学

在 `1201.9.0` 版本后，仔细搜刮 提供了**搜索进度音效**功能，让你在搜刮物品时获得更沉浸的音频反馈。

该功能默认关闭，因为我懒得做搜刮音效。

## 快速上手

1. 打开配置文件 `.minecraft/config/searchcarefully-common.toml`
2. 找到 `enableSearchProgressSound` 选项
3. 将其值改为 `true`
4. 保存文件

之后当你打开容器搜刮物品时，就会听到持续的搜刮音效。

## 循环音效的工作原理

搜索进度音效采用**循环播放**模式。

| 特性 | 说明 |
|------|------|
| 播放方式 | 音效持续循环播放，不会反复重新触发 |
| 启动条件 | 玩家打开容器且容器中有待搜刮物品时自动开始 |
| 停止条件 | 容器中所有物品搜索完成，或玩家关闭容器时立即停止 |
| 多人兼容 | 每位玩家独立播放，互不干扰 |
| 跟随玩家 | 音效位置跟随玩家移动，距离越远声音越小 |

## 配置详解

### 基本配置

```toml
[SearchProgressSound]
    # 启用搜索进度音效，默认关闭
    enableSearchProgressSound = true
```

### 自定义音效

你可以替换 `search_progress.ogg` 文件来自定义搜刮音效：

1. 找到模组 JAR 文件或资源包中的音效路径：
   `assets/searchcarefully/sounds/search_progress.ogg`
2. 准备你想要的 `.ogg` 格式音效文件
3. 将其放入资源包的对应路径

**注意**：循环音效要求音频文件适合循环播放——结尾和开头应当能无缝衔接，否则会听到明显的"咔哒"断层声。

## 常见问题

### Q: 开启音效后没有声音？

请检查以下几点：
- 确认 `enableSearchProgressSound` 已设为 `true`
- 检查游戏主音量及"方块音效"（SoundSource.BLOCKS）音量未关闭
- 确认容器中的物品确实有搜索时间（物品上应该有搜索动画覆盖）
- 检查是否安装了其他模组覆盖了音效文件

### Q: 音效太大了/太小了？

当前音效音量由游戏内的"方块音效"滑块控制。如果你需要更精确的控制，可以：
- 在资源包中替换音量更合适的音效文件
- 使用音频编辑软件调整原始 `.ogg` 文件的响度

### Q: 我只想搜刮完成时听到音效，不要搜刮过程中的音效？

你可以关闭 `enableSearchProgressSound`（设为 `false`），这样搜刮过程中不会播放循环音效，但**搜刮完成的提示音**（基于物品稀有度的音效）仍会正常播放。这两套音效系统相互独立。
