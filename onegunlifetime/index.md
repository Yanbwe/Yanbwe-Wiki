# OneGunLifetime（一人一枪一辈子）

OneGunLifetime 是 [ModularShoot（模块化射击）](../modularshoot/) 的附属拓展模组，运行于 NeoForge 1.21.1。它提供“灵魂绑定”射击玩法：**玩家绑定一把枪，这把枪就是玩家自己**。绑定后，玩家的数值与特性始终挂在玩家身上，背包中的枪只是投影入口；枪丢了会自动补回，其它枪械进入背包会被同化。

> **依赖**：本模组为 ModularShoot 的附属模组，**必需安装** [ModularShoot](../modularshoot/) 0.3.1 及以上版本，服务端与客户端均需安装。

## 功能一览

| 功能 | 说明 |
|------|------|
| **灵魂绑定** | 玩家通过命令一生绑定一次；绑定后生成一把专属投影枪，且数据以玩家实体为单真源 |
| **玩家就是这把枪** | 数值与插件修饰符直接挂在玩家实体上，空手或手持其它物品时同样生效 |
| **背包独占与同化** | 其它 ModularShoot 枪械进入背包会被替换/作废；插件会尝试并入，放不下的以插件物品返还 |
| **丢失补回** | 主动丢弃会被拦截并立即补回；被岩浆等销毁后自动重建；管理员 `/clear` 明确不补回 |
| **容器拒收** | 投影枪无法放入容器；漏网路径由低频容器回收兜底 |
| **插件兼容** | 安装/拆卸完全走框架语义，插件列表会自动回写灵魂数据 |
| **非持有者禁射** | 他人拾取投影枪无法发射；未绑定者得到的是纪念品而非可用枪械 |

## 快速上手

1. 安装本模组与 ModularShoot 0.3.1+（NeoForge 21.1.233+，MC 1.21.1）
2. 使用 `/onegun bind <枪械注册ID>` 绑定一把已注册枪械，例如 `/onegun bind modularshoot:demo_pistol`
3. 绑定后背包会出现你的专属投影枪；用 `/onegun stat set`、`/onegun trait add` 自定义数值与特性
4. 其它枪械进入背包会自动同化；丢弃/销毁后会自动补回
