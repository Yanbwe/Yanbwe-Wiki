## 兼容性问题及其解决方法

RarityCore与某些模组安装时，会导致功能异常，甚至游戏崩溃，这里列出了它们，并提供了解决方法。

## 设定稀有度

模组有 id匹配 和 nbt匹配 两种方式来设定物品的稀有度，你需要查看不同的文档来学习用法。(Tips：内含本模组添加的指令的相关信息)

- id匹配：稀有度配置指南
- NBT匹配：适用于1.20.1版本
- 物品组件匹配：适用于1.21.1+版本

## 客户端配置

如果你需要控制物品名称变色、工具提示插入、物品背景纹理，或制作包含物品背景纹理的资源包，请你查看这个页面。

## 服务端配置

如果你需要控制原版稀有度检测、神化模组的稀有度检测、无稀有度配置的物品的处理，请你查看这个页面。

## 查看支持的模组

如果你需要了解RarityCore联动了哪些模组，或了解RarityCore预置了哪些模组的稀有度信息，请你查看这个页面。

## 使用 API

如果你的模组需要获取本模组定义的稀有度，或是控制本模组的行为，请查看这个页面。
