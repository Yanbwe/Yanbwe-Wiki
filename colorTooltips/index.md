# ColorTooltips（灵动提示框）

高度自定义、丝滑动画的提示框模组。

告别原版那块灰扑扑的方框——ColorTooltips 让你像打扮物品一样打扮提示框。边框用什么颜色、背景透不透明、标题栏多高、颜色流不流动、淡入多快、闪光多长……全部由你说了算，写在 JSON 里，改完输入 `/colortooltips reload` 立刻生效。

推荐搭配 [RarityCore（稀有度核心）](/raritycore/) 使用，可为不同稀有度的物品自动匹配不同样式。未安装时使用原版稀有度配色，同样出色。

## 🎨 高度自定义

一切都可配置，精确到每个像素和每一帧：

- **颜色自由** — 你可以用稀有度主题色（`@rarityCore`、`@vanillaRarity`），也可以用任意十六进制颜色（`#FF5500`），还能叠加明度和饱和度微调
- **分区域控制** — 边框、背景、标题栏各自独立配置，互不干扰。每个区域可以有自己的颜色列表、透明度、流动方向和速度
- **样式选择器** — 不同物品、不同稀有度可以自动匹配不同的样式文件。普通物品一个样，稀有物品一个样，特定物品还能单独指定
- **热重载** — 在游戏里改完 JSON，敲 `/colortooltips reload`，即时预览，无需重启

四套预置样式开箱即用：**Vanilla**（简约白）、**VanillaRarity**（稀有度色）、**RarityCoreStyles**（完整稀有度光谱）、**RGB**（彩虹渐变色）。想自己写？[样式编写指南](/colorTooltips/StyleGuide) 带你上手。

## 🎬 丝滑动画

ColorTooltips 的动画从不偷懒——每一项都可独立开关、独立调速：

- **淡入淡出** — 提示框平滑出现、优雅消失，延迟和时长均可调，你也可以关掉让它瞬间闪现
- **位置缓动** — 跟随鼠标时带非线性过渡，从右侧跳到左侧时自然滑移过去，速度倍率随你调
- **尺寸过渡** — 提示框大小变化时平滑缩放，没有突兀的跳变
- **色彩流动** — 边框和标题栏的颜色沿边缘持续流动，速度、方向、开不开启都取决于你
- **物品模型动画** — 图标从缩放到正常大小，切换和出现各有独立的起始比例
- **切换闪光** — 鼠标移到不同物品时，一道可自定义颜色和长度的流光沿边框掠过
- **跨样式渐变** — 物品切换导致样式变化时，旧颜色淡出、新颜色淡入，无缝过渡

详见 [配置指南](/colorTooltips/ConfigGuide)。
