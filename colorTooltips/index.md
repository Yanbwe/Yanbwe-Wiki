# ColorTooltips（灵动提示框）

**Yanbwe 推荐你安装 RarityCore 以获得完整的色彩体验。本模组是围绕 RarityCore 打造的，未安装 RarityCore 时将降级为白色边框。**

---

ColorTooltips 是一个提供提示框样式的模组，具有以下核心特性：

## ✨ 绚丽
- **独特的提示框设计** — 基于 RarityCore 的稀有度系统，每个稀有度都有自己的主题色
- **渐变效果** — 边框和背景拥有流畅的渐变色彩

## 🎯 灵动
- **色彩流动** — 边框和标题栏背景具有舒适的颜色流动动画
- **淡入淡出** — 提示框不再生硬地瞬间出现和消失，带有平滑的淡出淡入效果
- **过渡动画** — 当提示框大小改变或从鼠标右侧切换到左侧时，具有非线性缓动动画
- **物品模型缓动** — 物品图标出现时有缩放动画
- **边框闪光** — 切换物品时边框带有闪光效果
- **颜色过渡** — 颜色变化有过渡动画

## 🔧 配置
- 支持配置背景透明度、颜色变化范围、动画时长等参数
- 详细配置请参考[配置指南](/colorTooltips/ConfigGuide.md)

## 🔗 兼容性
- 与 SearchCarefully 兼容
- 与 神化（Apotheosis）模组兼容
- **不兼容**修改提示框样式的模组，但兼容向其添加内容的模组

## 📦 依赖
- **推荐安装**: [RarityCore（稀有度核心）](/raritycore/)
