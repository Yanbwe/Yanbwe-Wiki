## Compatibility Issues and Their Solutions

When RarityCore is installed alongside certain mods, it may cause functional anomalies or even game crashes. These issues are documented here along with their solutions.

## Set Rarity

The mod offers two methods for setting item rarity: id matching and nbt matching. You need to refer to different documentation to learn how to use them. (Tips: Contains information about commands added by this mod)

- ID Matching: Rarity Configuration Guide
- NBT Matching: For version 1.20.1
- Item Component Matching: For version 1.21.1+
