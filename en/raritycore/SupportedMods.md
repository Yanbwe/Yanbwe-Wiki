# Supported Mods List

This document lists all mods that currently have pre-configured rarity information in RarityCore.

## Version

The current latest rarity configuration version is `3`

You can find the version of the rarity configuration in the mod's version number, which follows the format: `<Minecraft version>.<Mod version>.<Rarity configuration version>`.

Currently supporting **76** mods with pre-configured rarity information.
