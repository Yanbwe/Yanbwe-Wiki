# ColorTooltips

**Yanbwe recommends installing RarityCore for the full color experience. This mod is built around RarityCore. Without RarityCore, it will fall back to a white border.**

---

ColorTooltips is a mod that provides tooltip styling, featuring the following core features:

## ✨ Vibrant
- **Unique tooltip design** — Based on RarityCore's rarity system, each rarity level has its own theme color
- **Gradient effects** — Smooth gradient colors on borders and backgrounds

## 🎯 Dynamic
- **Color flow** — Borders and title bar backgrounds feature a smooth color-flowing animation
- **Fade in/out** — Tooltips no longer appear and disappear abruptly; they have smooth fade-in and fade-out effects
- **Transition animation** — Non-linear easing animations when the tooltip resizes or switches from the right to the left side of the cursor
- **Item model easing** — Scale animation when the item icon appears
- **Border flash** — Border flash effect when switching items
- **Color transition** — Smooth color transition animations

## 🔧 Configuration
- Supports configuring background alpha, color variation range, animation duration, and more
- See the [Config Guide](/en/colorTooltips/ConfigGuide.md) for details

## 🔗 Compatibility
- Compatible with SearchCarefully
- Compatible with Apotheosis
- **Not compatible** with mods that modify tooltip styles, but compatible with mods that add content to tooltips

## 📦 Dependencies
- **Recommended**: [RarityCore](/en/raritycore/)
