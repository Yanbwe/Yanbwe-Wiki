Welcome to SearchCarefully!

This is a Minecraft mod that adds a search time feature to loot chests.

**SearchCarefully** is a mod designed for multiplayer environments. In multiplayer, chest loot is usually generated on the server side to prevent cheating. However, this often leads to situations where players can quickly scan through all available items to find the best ones.

This mod addresses that issue by introducing a search time mechanism.
